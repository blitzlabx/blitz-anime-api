Quick Start

Free public API by Blitz (blitzlabx). Search, stream, download anime episodes and manga chapters. Perfect for apps, bots and websites.

Base URL: https://your-render-url.onrender.com

Test /health →

Health & Uptime

GET /health
GET /ping

Use for UptimeRobot, cron-job.org or Render health checks. Returns JSON with Blitz signature.

Providers

GET /api/v1/providers

Anime: allmanga, gogoanime, animeparadise, anikoto, megaplay, goyabu

Manga: mangadex, weebcentral, mangapill

Meta: anilist, mal, kitsu

Search (Anime or Manga)

GET /api/v1/search?q=Frieren&provider=allmanga
GET /api/v1/manga/search?q=Frieren&provider=mangadex

Episodes / Chapters

GET /api/v1/content?id=allmanga:xxxxx
GET /api/v1/content?id=mangadex:xxxxx

Resolve Stream / Pages

GET /api/v1/stream?id=allmanga:xxxxx/1&language=sub
GET /api/v1/stream?id=mangadex:xxxxx

Anime returns HLS/MP4. Manga returns high-res page image URLs.

Download Video (MP4)

GET /api/v1/download/video?id=allmanga:xxxxx/1&language=sub

Resolves stream then converts HLS → MP4 using ffmpeg (server-side). Returns the file.

Download Manga Chapter (ZIP)

GET /api/v1/download/manga?id=mangadex:xxxxx

Packs all chapter pages into a ZIP and streams it to the client.

Metadata Layer

GET /api/v1/meta/search?q=Frieren&meta=anilist
GET /api/v1/meta/info?id=anilist:21
GET /api/v1/meta/browse?type=trending&catalogType=ANIME
GET /api/v1/meta/stream?id=anilist:21&episode=1&provider=allmanga
